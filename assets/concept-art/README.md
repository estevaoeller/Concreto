# Concreto: estudos de personagem

Referência visual preliminar, criada em 15/11/2026. Não constitui asset aprovado.

Arquivo previsto: `concreto-estudos-personagem.png` (upload pendente).

Quatro alternativas: A verde clássico, B azul descolado, C roxo fofo, D laranja aventureiro. A prancha usa A para demonstrar as ações, sem aprovar a escolha definitiva.

Estudos: parado, caminhada, salto com compressão e extensão, gota desprendida, preparação e disparo do raio de geleca, espada e demonstração de plataforma lateral.

Divergência: a espada empunhada pelo protagonista contraria A02 da especificação vigente. A arma pertence ao monstro; não implementar espada no protagonista sem validação expressa com o criador. Corações, moedas, cenário e demais elementos ilustrativos também não constituem novos requisitos.

Desenvolvimento futuro na nuvem, utilizando este repositório como fonte de referência. Plataforma, tecnologia e início da implementação ainda não definidos.
