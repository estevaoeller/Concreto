# Prompts de produção visual

Cada arquivo contém um prompt independente, pronto para copiar no GPT Images. Gerar uma prancha por vez. Os prompts não são especificações de gameplay; propostas de arte e cenário precisam de validação.

## Ordem recomendada

1. [Concreto](personagens/concreto.md) — aprovar a aparência antes de reutilizá-la.
2. [Mundo 1 — plantas](storyboards/01-plantas.md) e [Cthulhu Higiênico](personagens/boss-01-cthulhu.md).
3. [Mundo 2 — Nether](storyboards/02-nether.md) e [boss vulcânico / referência Malgosha](personagens/boss-02-malgosha.md).
4. [Mundo 3 — céu](storyboards/03-ceu.md) e [anjo](personagens/boss-03-anjo.md).
5. [Mundo 4 — pelúcias](storyboards/04-pelucias.md) e [coelho](personagens/boss-04-coelho.md).
6. [Mundo 5 — blocos](storyboards/05-blocos.md) e [boss final](personagens/boss-05-bloco.md).
7. [Monstros comuns](personagens/monstros-comuns.md).

Anexar a referência aprovada do Concreto em cada nova geração. Quando houver, anexar também o boss do mundo. A ordem pode ser invertida entre storyboard e boss para melhorar consistência. Manter o mesmo estilo escolhido, evitando que cada prancha redesenhe o protagonista.

Salvar os PNGs no [catálogo de concept art](../assets/concept-art/README.md). Não interpretar pranchas geradas como sprites prontos ou regras de jogo. A espada anteriormente desenhada para Concreto não deve ser reproduzida.
