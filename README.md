# Concreto

Jogo de plataforma em fase de descoberta e preparação para desenvolvimento. Concreto é uma geleca com formato de fantasma que atravessa plataformas e enfrenta monstros. A visão é lateral durante a exploração; o combate contra o Cthulhu Higiênico muda para primeira pessoa.

## Estado atual

Especificação de gameplay v0.4 (2026-11-15): personagem, controles básicos, três vidas, portais, ciclo de dia e noite, cinco mundos temáticos e padrão de combate contra bosses. Pacote de preparação para desenvolvimento e produção visual publicado. Não há código nem stack escolhida. Regras pendentes continuam explicitadas na especificação.
